# 🎓 Навчальна лабораторія

**Інтерактивна освітня платформа для вивчення математики та інформатики учнями 1–11 класів.**

Навчальна лабораторія — це вебплатформа, створена для організації сучасного, доступного та інтерактивного навчання. Проєкт поєднує навчальні матеріали, практичні завдання, інтерактивні уроки та елементи гейміфікації, щоб зробити освітній процес цікавішим і мотивувати учнів до самостійного опанування знань.

## ✨ Можливості

- 📚 **Навчальний каталог** — структуровані навчальні матеріали з математики та інформатики.
- 🧑‍🎓 **Навчання для 1–11 класів** — організація матеріалів відповідно до шкільних рівнів.
- 💻 **Інтерактивні уроки** — теоретичні пояснення, наочні приклади, практичні вправи та перевірка знань.
- 🎮 **Гейміфікація** — навчальна валюта «комп’юшки», досягнення та заохочення за виконання завдань.
- 🌓 **Світла й темна теми** — можливість обрати комфортний вигляд інтерфейсу.
- 📱 **Адаптивний інтерфейс** — зручне використання на комп’ютерах, планшетах і смартфонах.
- 🧭 **Зручна навігація** — каталог предметів, переходи між уроками та навігаційна панель.
- 📈 **Відстеження прогресу** — підтримка локального збереження навчальних результатів.

## 📖 Навчальні напрями

### ➗ Математика
Навчальні матеріали, пояснення математичних понять, приклади розв’язання задач та інтерактивні вправи для закріплення знань.

### 💡 Інформатика
Матеріали з основ інформатики, алгоритмізації, програмування, цифрових технологій та інших тем шкільного курсу.

## 🛠️ Технології

Проєкт розроблений із використанням вебтехнологій:

- **HTML5** — структура сторінок.
- **CSS3** — оформлення інтерфейсу, адаптивність і теми.
- **JavaScript** — інтерактивність, навігація, робота з навчальним каталогом і гейміфікація.
- **JSON** — структуроване зберігання даних навчального каталогу.
- **LocalStorage** — локальне збереження підтримуваних даних користувача.
- **GitHub Pages** — безкоштовне розміщення статичного вебсайту.

## 📂 Структура проєкту

```text
ModernEducationApp/
├── index.html              # Головна сторінка
├── css/                    # Стилі та дизайн-система
├── js/                     # Логіка та інтерактивні функції
├── data/                   # Дані навчального каталогу
├── subjects/               # Сторінки навчальних предметів
├── lessons/                # Навчальні сторінки (якщо передбачено структурою)
└── README.md               # Опис проєкту
```

*Фактична структура папок може відрізнятися залежно від поточної версії проєкту.*


## 💾 Збереження даних

Підтримувані результати навчання та інші дані можуть зберігатися в локальному сховищі браузера. Це означає, що вони не синхронізуються автоматично між різними пристроями або браузерами й можуть бути втрачені після очищення даних сайту.
