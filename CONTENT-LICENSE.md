# Ліцензування навчальних матеріалів і дизайну

За замовчуванням авторські навчальні тексти, завдання, пояснення, оригінальні ілюстрації, графічний дизайн і бренд «Навчальної лабораторії», права на які належать автору, не надаються для повторного використання лише через те, що репозиторій є публічним.

Для цих матеріалів діє файл `LICENSE`, якщо для конкретного файлу не зазначено інші умови. Сторонні зображення, шрифти, іконки, бібліотеки та інші ресурси можуть мати окремі ліцензії — перевіряйте їх перед використанням.

Назва та логотип можуть підпадати під окремі правила щодо торговельних марок. Наявність авторського права на код не означає автоматичного оформлення прав на торговельну марку.

Цей файл є інформаційним поясненням і не замінює юридичної консультації.
